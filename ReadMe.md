# Стек технологий проекта MiniLui
    MiniLui - пет-проект на java, Spring-boot для сокращения ссылок (аналог bitLy) и 
    сборки аналитических данных об использовании созданных ссылок.

## Ядро
- **Java 21**
- **Spring Boot 4.0.6**
- Spring Web
- Spring Security
- Spring Data JPA
- Spring Data Redis
- Spring Data Reactive Redis
- Docker Compose Support

## Базы данных
- **PostgreSQL** 
- **Redis** 

## Шаблонизаторы
- **Thymeleaf**

## Утилиты
- **Lombok** 
- **Yauaa** анализ 
- **GeoIP2** геолокация по IP

## Валидация
- **Jakarta Validation API** 

## Сборка
- **Maven** 
  - `spring-boot-maven-plugin`
  - `maven-compiler-plugin`
